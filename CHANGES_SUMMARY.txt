                          FEATURES ADDED (#3)
================================================================================

FEATURE 1: Auto-Save Form Drafts
────────────────────────────────────────────────────────────────────────────
What:   Form data automatically saved to browser localStorage
When:   Every time user types in form fields
Result: User's message is never lost, even if:
        - Browser crashes
        - Internet connection drops
        - User accidentally closes tab
        - Page is refreshed

FEATURE 2: Offline Status Banner
────────────────────────────────────────────────────────────────────────────
What:   Red banner appears when user goes offline
Where:  Top of page with message: "You are offline – messages will be saved locally"
Auto-hides: When connection is restored
Benefits: Clear user feedback about connection status

FEATURE 3: Smart Error Handling
────────────────────────────────────────────────────────────────────────────
Offline Error:
  "You're offline. Your message has been saved. You can:
   1. Come back when online to send it
   2. Email me at srikarpuyal.me@gmail.com"

Server Error:
  "Failed to send message. Email me at..."

FEATURE 4: Draft Restoration
────────────────────────────────────────────────────────────────────────────
What:   When page loads, form is auto-populated from localStorage
Result: User never loses their message content
